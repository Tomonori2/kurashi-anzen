# くらしの安全相談AI

詐欺電話への対応・暮らしの安全相談・通話録音の詐欺判定を、1つにまとめたスマホ向けアプリです。

**👉 [アプリを開く](https://tomonori2.github.io/kurashi-anzen/)**

---

## できること

| | 内容 | APIキー |
|---|---|---|
| 📞 いま電話が来ている | 通話しながら見る警告リスト。#9110への発信、あやしい番号かどうかの確認 | **不要** |
| 💬 相談したい | 詐欺・防犯からご近所トラブル・暮らしの困りごとまで、文章で相談できる | 必要 |
| 🎧 通話の録音を調べる | 録音を文字に起こし、詐欺の危険度（高・中・低）を判定する | 必要 |

**今まさに危険なとき・被害が起きているときは、迷わず110番へ。**
このアプリの答えは一般的な防犯情報です。

## 使い方

### 1. ホーム画面に追加する（おすすめ）

スマホのブラウザでアプリを開き、メニューから「ホーム画面に追加」を選びます。
アイコンを**長押し**すると「いま電話が来ている」へ直接飛べます。

### 2. APIキーを登録する（相談・録音判定を使う場合だけ）

右上の ⚙️ から、GoogleのAI「Gemini」のAPIキーを貼り付けます。
キーは [Google AI Studio](https://aistudio.google.com/apikey) で**無料**で取得できます。

🔒 **キーはあなたのスマホの中にだけ保存されます。** 開発者を含む誰にも送信されません。

### 3. 録音を調べる

録音ファイルを開いて「共有」→ このアプリを選ぶだけで、文字起こしと判定が始まります。
アプリ内の「🎵 録音ファイルを選ぶ」からでも同じことができます。

※ 12MB・20分前後までの音声に対応しています。

## 知っておいてほしいこと

- **通話中にアプリが録音することはできません。** Androidの制限で、通話中はブラウザのアプリがマイクを使えません。録音はスマホの電話アプリ側の機能を使ってください
- 危険な電話番号の記録は、**あなたの端末の中だけ**に保存されます
- 「確認済み」として表示される番号は、このリポジトリで共有している情報です

## 仕組み

HTML1ファイルで動く静的アプリです。サーバーは持たず、GitHub Pagesで配信しています。

- AIは Google Gemini（利用者が自分のキーを設定するBYOK方式）
- `knowledge.js` に防犯・暮らしの知識を持ち、相談内容や通話内容に関係するものを選んでAIに渡します
- PWA（manifest + Service Worker）対応。ホーム画面に置けて、電波が悪くても画面は開きます

## 危険な番号の情報提供

あやしい電話番号を見つけたら [Issues](https://github.com/Tomonori2/kurashi-anzen/issues) で教えてください。
確認のうえ、みんなに共有する一覧へ追加します。
