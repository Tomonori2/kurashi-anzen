📮 メール見張り番

くらしの安全相談AI の仲間
← アプリへ戻る

あなたのGmailを1時間ごとに見回って、詐欺っぽいメールが届いたら知らせてくれる仕組みです。

いつ何が届くか
危険なメールが来たとき
（1時間以内）		「【メール見張り番】危険なメールが届いています」
あやしい理由と、どうすればいいかが書いてあります
毎朝7時ごろ「けさのまとめ」＝見たメールの数・危険・注意の一覧。
届くこと自体が「ちゃんと動いている」証明です
  • 無料です。AIは使いません。
  • 判定はあなたのGoogleアカウントの中だけで行います。メールの中身は、作者にもほかの誰にも届きません。
  • メールを消す・動かす・返信する・転送する、は一切しません。読むだけです。
  • 見分け方は、アプリの「🔍 これ、あやしい？」と同じです。それに、送り主のなりすまし確認を足しています。

💻 パソコンが必要です　最初の設定（15〜20分）だけ。そのあとは何もしなくても動き続けます。

⚠️ はじめる前に、必ず読んでください

これは「あなたのメールを読む許可」をプログラムに与える仕組みです。だから、次のことを守ってください。

  • コードはこのページ（tomonori2.github.io/kurashi-anzen/）からだけコピーしてください。メール・SNS・LINEで送られてきたコードは使わないでください。
  • 知らない人から「このコードを貼って」「この許可を押して」と言われたら、それ自体が詐欺です。同じ手口でメールを乗っ取る犯罪があります。
  • 許可の画面に「メールの完全な削除」「Googleドライブのすべてのファイル」「連絡先」が出たら、中止してください。この仕組みは求めていません。
  • 会社や仕事のメールには使わないでください。自分の個人のGmailだけにしてください。

1新しいプロジェクトを作る

  1. パソコンのブラウザ（Chromeなど）で https://script.google.com を開きます（いつものGoogleアカウントで）
  2. 左上の「＋ 新しいプロジェクト」を押します
  3. 上の「無題のプロジェクト」を押して、名前を「メール見張り番」に変えます

2設定ファイルを見えるようにする

  1. 画面のいちばん左の細い列にある歯車マーク ⚙（プロジェクトの設定）を押します
  2. 「「appsscript.json」マニフェスト ファイルをエディタで表示する」にチェックを入れます
  3. 左の列の ＜＞（エディタ）を押して戻ります。appsscript.json と コード.gs が並んでいればOKです

このチェックを忘れると、Googleが必要以上に広い許可を求めてきます。

33つのファイルを貼る

どれも同じやり方です：下のボタンでコピー → エディタで左のファイル名を押す → 右の中身をクリック → Ctrl + A（全部選ぶ）→ Ctrl + V（貼る）

① appsscript.json
許可を「読むだけ」にしぼる設定
② コード.gs
見回り・お知らせ・朝のまとめの本体
③ Engine.gs（新しく作る）
左の「ファイル」の横の ＋ →「スクリプト」→ 名前に Engine と入れて Enter。それから貼ります

3つ貼ったら Ctrl + S で保存します。中身はすべて、貼ったあとエディタで読めます。隠れた部分はありません。

4まず「試し」で判定だけ見る

  1. 左の コード.gs を押してから、上の「▷ 実行」の右にある関数のボックスで tryRecent を選びます
  2. ▷ 実行 を押します。許可の画面が出たら、次の5へ
  3. 画面の下の「実行ログ」に、最近20通の判定（なし／【注意】／【危険】）が並びます

ここではメールは送られません。いつものお店や銀行の本物のメールが【危険】になっていないか、見てください。

5許可の画面（いちばんの山場）

  1. 「承認が必要です」→「権限を確認」
  2. 自分のアカウントを選び、「次へ」
  3. 「このアプリは Google で確認されていません」と出たら、左下の小さな「詳細」→「メール見張り番（安全ではないページ）に移動」
    個人が作ったプログラムで、Googleの審査を受けていないために出る注意です。作ったのは今のあなた自身です。
  4. 許可する内容を確かめて「すべて選択」→「続行」
出てくる文言何に使うか
メール メッセージと設定の表示受信箱を読んで判定する（読むだけ）
ユーザー本人に代わってのメールの送信自分あてのお知らせを送る
自分がいないときにこのアプリケーションを実行1時間ごと・毎朝の見回り

この3つ（と、メールアドレスの確認）だけです。「削除」「ドライブ」「連絡先」があったら中止してください。

6見張りを始める

  1. 関数のボックスを setup に変えて、▷ 実行
  2. Gmailに「【メール見張り番】見張りを始めました」が届けば完成です
  3. 次の朝7時ごろ「けさのまとめ」が届くかを確かめてください

始めたときに、この24時間に届いたメールも1回見ます。危険なものがあれば、すぐにお知らせが届きます。

知っておいてほしいこと

  • 完ぺきではありません。詐欺の特徴で見分けているので、新しい手口は見のがすことがあります。「お知らせが来ない＝安全」とは思わないでください。
  • お店のセールのメールが「注意」に入ることがあります。「注意」は朝のまとめに入るだけで、すぐのお知らせは来ません。
  • お知らせの中のあやしいリンクは hxxps://example[.]top のように、押せない形に崩してあります。
  • Gmailがすでに迷惑メールに入れたものは見ません。すり抜けてきたものを拾う「二重のチェック役」です。
  • SMS・LINE・電話は見られません。それはアプリの「🔍 これ、あやしい？」に貼って調べてください。

困ったとき・やめたいとき

こんなときどうする
朝のまとめが届かない迷惑メールフォルダを確認 → なければ setup をもう一度実行
「必要な権限がありません」と出る手順2のチェックと、①の貼り付けを確かめてください。自分で広い許可に書きかえないでください
本物のメールが「危険」と出たいつもの公式アプリや公式サイトから確かめてください。アプリの「ご意見を送る」で、送り主のアドレスと件名を教えてもらえると判定を直せます（本文は送らないでください）
やめたいscript.google.com で「メール見張り番」を開き、左の時計マーク（トリガー）で2つとも削除。プロジェクトごと消してもかまいません
